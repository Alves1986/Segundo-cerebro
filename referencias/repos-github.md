# Repositórios do GitHub (Alves1986)

Índice mestre dos meus repositórios em https://github.com/Alves1986. Todo repo tem link direto pro GitHub. Repos que já estão clonados no disco apontam também pra pasta local. Esta é a referência que o cerebro usa pra rotear quando eu cito um repo, uma lib ou uma ferramenta.

**Como usar:** quando eu disser "olha o repo X" ou "usa a lib Y do meu github", o cerebro busca aqui, abre o link e (se estiver no disco) a pasta local. Não se clona repo só pra dentro do vault: o código fica no GitHub ou na pasta real.
