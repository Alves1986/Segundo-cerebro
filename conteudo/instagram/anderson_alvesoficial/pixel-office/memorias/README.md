## 📌 Regras do time
1. **Treinável:** cada trabalho concluído gera aprendizado registrado na memória do agente.
2. **Aprovação humana:** nada é salvo sem o Anderson revisar e aprovar.
3. **Correção direcionada:** se algo precisa mudar, volta pro agente responsável (não refaz tudo).
4. **Nível sobe com consistência:** a cada 5 trabalhos aprovados sem retrabalho, o agente sobe de nível.
