# Prompt pro Antigravity — Clonar Voz no Voicebox

```
/opensquad run instagram-content

TAREFA: Usar o Agente Browser para operar o Voicebox (http://localhost:5173) e clonar a voz do Anderson.

INSTRUÇÕES:

1. Abra o navegador e acesse http://localhost:5173

2. Na tela do Voicebox, localize a opção de CLONAR VOZ (Voice Cloning)

3. Faça upload do arquivo de áudio:
   ~/SegundoCerebro/conteudo/voz-anderson-clonagem.mp3

4. Após a clonagem, gere o áudio com o seguinte texto:
   "Fala, sou Anderson Alves. Sou parceiro da Vertex Consulting e crio sites profissionais para negócios locais em Telêmaco Borba. Site com CRM, WhatsApp integrado, sistema de agendamento. Bora fazer o seu? Me chama no direct."

5. Baixe/salve o áudio gerado em:
   ~/SegundoCerebro/conteudo/voz-gerada-apresentacao.mp3

6. Confirme que o arquivo foi salvo com sucesso.
```

Cole esse prompt no Antigravity que o Agente Browser faz tudo sozinho! 🚀
