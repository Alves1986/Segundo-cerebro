# Prompt — Extração Instagram Evolute

Cole no Antigravity:

```
/opensquad run instagram-content

TAREFA: Executar auditoria completa do Instagram @evolute.odonto.psico

Use o Agente Browser para acessar o perfil e extrair:

1. IDENTIDADE
- Nome de exibição e @handle
- Categoria do Instagram
- Bio completa (texto literal)
- Link(s) na bio
- Telefone/WhatsApp/e-mail/endereço
- Localização/cidade
- Seguidores / Seguindo / Posts

2. IDENTIDADE VISUAL
- Paleta de cores dominante
- Estilo fotográfico
- Consistência de identidade visual
- Proporção foto vs Reels

3. CONTEÚDO E OFERTA
- Categorias de posts mais recorrentes
- Produtos/serviços identificados
- Diferenciais que o perfil destaca
- Destaques (Stories) e títulos

4. PÚBLICO E ENGAJAMENTO
- Tom de voz
- Hashtags recorrentes
- Nível de engajamento

5. EXTRAIR NOMES DOS SÓCIOS
- Os nomes estão nas fotos fixadas no início do perfil
- Pegar o nome de cada um e a especialidade

Entregue o resultado em Markdown com todos os campos preenchidos.
Marque como NÃO DISPONÍVEL o que não encontrar.
```
