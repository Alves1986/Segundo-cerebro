# Design System — Plataforma de IA para Vídeos Virais

## 1. Direção visual
A interface deve transmitir energia, modernidade e performance. O estilo ideal combina base escura, acentos vibrantes e tipografia forte para apoiar uma proposta de vídeos virais.

## 2. Paleta de cores
### Base
- Fundo: #0F172A
- Superfície: #111827
- Texto principal: #F9FAFB
- Texto secundário: #CBD5E1

### Acentos
- Primária: #7C3AED
- Secundária: #22D3EE
- Destaque: #FACC15
- Sucesso: #39FF14
- Erro: #FF4D4D

## 3. Uso das cores
- Roxo para identidade principal e botões primários.
- Ciano para elementos tecnológicos e links.
- Amarelo para pontos de atenção e chamadas fortes.
- Verde neon para estados de progresso e confirmação.
- Vermelho apenas para alertas.

## 4. Tipografia
- Títulos: sans-serif pesada, moderna e de alta legibilidade.
- Corpo: sans-serif limpa e neutra.
- Destaques: uso moderado de caixa alta e negrito.

## 5. Componentes
- Botão primário.
- Botão secundário.
- Cards de projeto.
- Bloco de roteiro.
- Bloco de visual.
- Tags de estilo.
- Chips de plataforma.
- Modal de exportação.

## 6. Regras de UI
- Alto contraste em todos os textos.
- Ícones simples e funcionais.
- Layout com bastante respiro.
- Foco em mobile first.
- Feedback visual claro para ações.

## 7. Direção para thumbnails e dashboards
- Texto curto e muito legível.
- Hierarquia visual forte.
- Contraste alto.
- Elementos de impacto nas bordas e centro.
- Cores mais quentes para chamadas de ação.

## 8. Estado visual por emoção
- Educativo: azul e ciano.
- Polêmico: vermelho e amarelo.
- Premium: preto, roxo e dourado.
- Humor: cores mais saturadas.
- Storytelling: tons escuros e cinematográficos.
