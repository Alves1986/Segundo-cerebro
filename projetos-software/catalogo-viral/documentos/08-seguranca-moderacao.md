# Segurança e Moderação — Plataforma de IA para Vídeos Virais

## 1. Objetivo
Proteger a plataforma, os usuários e a qualidade do conteúdo gerado.

## 2. Riscos principais
- Prompts maliciosos.
- Conteúdo ofensivo.
- Uso indevido de marca ou direitos autorais.
- Saídas inconsistentes.
- Exposição de dados do usuário.

## 3. Medidas de proteção
- Validação de entrada.
- Filtros de conteúdo.
- Limites de uso.
- Logs de auditoria.
- Controle de acesso por conta.

## 4. Moderação de saída
O sistema deve revisar a geração antes de exibir ao usuário quando houver risco de:
- violência.
- ódio.
- assédio.
- conteúdo sexual explícito.
- informações sensíveis.

## 5. Privacidade
- Coletar apenas dados necessários.
- Informar uso de conteúdo para geração.
- Permitir exclusão de projetos.
- Proteger dados em repouso e em trânsito.

## 6. Boas práticas
- Não expor prompts internos.
- Não misturar projetos de usuários diferentes.
- Ter mensagens claras de erro.
- Permitir revisão manual antes da exportação.

## 7. Conteúdo de marca
Quando o usuário trabalhar com marca, o sistema deve respeitar tom, restrições e vocabulário permitido.
