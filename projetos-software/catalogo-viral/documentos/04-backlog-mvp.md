# Backlog MVP — Plataforma de IA para Vídeos Virais

## 1. Objetivo do MVP
Entregar o núcleo de valor o mais rápido possível: gerar roteiro e dashboard visual a partir de um tema.

## 2. Épicos
### Épico 1 — Criação de projeto
- Como usuário, quero criar um projeto novo.
- Como usuário, quero definir tema, objetivo e plataforma.

### Épico 2 — IA de roteiros
- Como usuário, quero receber um gancho forte.
- Como usuário, quero receber o roteiro completo.
- Como usuário, quero gerar variações.

### Épico 3 — IA de imagens
- Como usuário, quero receber paleta, layout e direção visual.
- Como usuário, quero ver uma prévia do dashboard.

### Épico 4 — Revisão e exportação
- Como usuário, quero editar o conteúdo.
- Como usuário, quero exportar em Markdown.

### Épico 5 — Histórico
- Como usuário, quero salvar e duplicar projetos.

## 3. Prioridade
### P0
- Criar projeto.
- Gerar roteiro.
- Gerar visual.
- Exportar Markdown.

### P1
- Variações por estilo.
- Histórico.
- Edição manual.

### P2
- Templates avançados.
- Analytics.
- Integrações externas.

## 4. Critérios de aceite
- O usuário consegue criar um projeto em menos de 2 minutos.
- O sistema gera roteiro e visual sem falhar para entradas simples.
- O conteúdo pode ser exportado e reutilizado facilmente.

## 5. Entregas do MVP
- Home.
- Formulário de criação.
- Tela de resultado.
- Editor básico.
- Exportação.
