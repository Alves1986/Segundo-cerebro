# UX e Fluxos — Plataforma de IA para Vídeos Virais

## 1. Objetivo da experiência
A experiência deve ser rápida, intuitiva e focada em reduzir fricção. O usuário precisa sentir que vai do conceito ao roteiro e ao visual em poucos passos.

## 2. Fluxo principal
1. Usuário entra na plataforma.
2. Cria um novo projeto.
3. Informa tema e objetivo.
4. Escolhe plataforma de destino.
5. Seleciona estilo e tom.
6. Recebe roteiro gerado.
7. Recebe dashboard visual.
8. Edita, salva e exporta.

## 3. Telas principais
### 3.1 Home
- Botão de criar projeto.
- Acesso ao histórico.
- Destaque para o benefício principal.

### 3.2 Criação de projeto
- Nome do projeto.
- Tema.
- Objetivo do vídeo.
- Plataforma.
- Duração estimada.
- Público-alvo.

### 3.3 Geração de roteiro
- Resultado do gancho.
- Resultado do roteiro completo.
- Variações de tom.
- Botão para reescrever.
- Botão para exportar.

### 3.4 Dashboard visual
- Preview da direção visual.
- Paleta de cores.
- Tipografia.
- Layout sugerido.
- Miniaturas e cards.

### 3.5 Histórico
- Lista de projetos.
- Busca.
- Favoritos.
- Duplicar projeto.

## 4. Princípios de UX
- Menos campos, mais resultado.
- Texto claro e sem jargão técnico.
- Feedback visual imediato.
- Controle para revisar antes de exportar.
- Compatibilidade total com mobile.

## 5. Interações principais
### 5.1 Criar roteiro
O usuário insere o tema e escolhe parâmetros. O sistema responde com um roteiro pronto e três variações.

### 5.2 Ajustar tom
O usuário muda o estilo para educativo, humor, polêmico ou storytelling. O roteiro é regenerado.

### 5.3 Gerar visual
A IA de imagens cria um painel com foco em legibilidade, contraste e energia visual.

### 5.4 Exportar
O usuário salva o resultado em Markdown, PDF ou copia para a área de transferência.

## 6. Microcopy sugerida
- "Transforme uma ideia em conteúdo pronto."
- "Gere ganchos mais fortes."
- "Crie roteiro e visual no mesmo fluxo."
- "Edite antes de exportar."

## 7. Estado vazio
Quando não houver conteúdo, mostrar exemplos de uso e modelos prontos para acelerar a primeira criação.

## 8. Estado de erro
Quando o tema estiver vago, orientar o usuário com perguntas simples, como nicho, objetivo e público.
