# Biblioteca de Prompts — IA de Roteiros e Imagens

## 1. Prompt base para roteiro
Gere um roteiro curto e viral sobre [tema], para [plataforma], com objetivo [objetivo], tom [tom], público [público], duração [duração]. Estruture em gancho, desenvolvimento, ponto de virada e CTA. Traga 3 variações de abertura e 3 CTAs diferentes.

## 2. Prompt base para reescrita
Reescreva o roteiro abaixo para deixá-lo mais curto, mais direto e com mais retenção. Preserve a ideia principal, melhore a linguagem falada e deixe o texto mais natural para vídeo curto.

## 3. Prompt base para variações de estilo
Pegue este roteiro e gere versões nos estilos educativo, humorístico, polêmico e storytelling. Mantenha a mesma ideia central, mas adapte ritmo, linguagem e CTA.

## 4. Prompt base para dashboard visual
Crie um dashboard visual para o roteiro abaixo. Defina paleta, tipografia, layout, hierarquia visual, destaques e sugestões de imagem. O resultado deve ser pensado para mobile e para vídeo viral.

## 5. Prompt de gancho
Crie 10 ganchos curtos e fortes para o tema [tema]. Os ganchos devem ser diretos, rápidos e adequados para TikTok, Instagram Reels e YouTube Shorts.

## 6. Prompt de CTA
Crie 10 chamadas para ação para este conteúdo. O CTA deve combinar com um vídeo curto e incentivar retenção, comentário, compartilhamento ou clique.

## 7. Prompt de adaptação por plataforma
Adapte o conteúdo abaixo para TikTok, Instagram Reels e YouTube Shorts. Explique o que muda em ritmo, duração, legenda e CTA.

## 8. Prompt de paleta
Sugira uma paleta de cores para um produto voltado a criadores de vídeos virais. A paleta deve ter base escura, alto contraste e acentos vibrantes.

## 9. Prompt de thumbnail
Crie uma sugestão de thumbnail com texto curto, foco em contraste, emoção e hierarquia visual forte.

## 10. Regras da biblioteca
- Sempre pedir contexto mínimo.
- Sempre permitir versão curta e versão longa.
- Sempre gerar alternativas.
- Sempre manter o texto editável.
