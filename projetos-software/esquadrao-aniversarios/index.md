# Cartão de Aniversário

Sistema online para criação de cartões de aniversário personalizados.

## Funcionalidades

- Criação de cartões masculinos e femininos
- Upload de foto com ajuste de posição e zoom
- Edição online totalmente no navegador
- Download do cartão em PNG
- Compartilhamento direto via WhatsApp

## Tecnologias

- Next.js 16.3 (App Router)
- React 19
- TailwindCSS
- Canvas API para renderização

## Instalação

\`\`\`bash
npm install
npm run dev
\`\`\`

## Deploy

O sistema pode ser hospedado no Vercel ou em qualquer hospedagem Node.js.
