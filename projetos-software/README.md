- Pra gravar uma nota de projeto (bug, feature, decisão, reunião): crie o arquivo dentro da pasta do projeto.
- Pra abrir o código: clique no link `file:///` da nota `index.md` do projeto.
- Regra de ouro: o output nasce dentro do objeto a que serve (decisão do Catálogo Viral vai em `catalogo-viral/`, não solta).
