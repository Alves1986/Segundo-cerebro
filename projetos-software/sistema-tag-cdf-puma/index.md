# Sistema TAG - Caldeira de Força (Puma)

Sistema completo de gestão de equipamentos industriais com busca inteligente, notas de manutenção e histórico fotográfico. É a implementação de software do conhecimento da base TAG KOS.

**Stack:** React + TypeScript + Vite + Tailwind + Supabase (modo local com localStorage funciona sem backend).
