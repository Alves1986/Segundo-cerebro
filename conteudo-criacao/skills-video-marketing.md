# Skills de Marketing para Geração de Vídeos

Salvo em: 12/08/2026

Lista de skills mais relevantes para criar vídeos para clientes, organizadas por categoria.

## Skills de Geração e Edição de Vídeo

### 1. sora (opendesign)
- API: OpenAI Sora
- Uso: Geração, remix e gestão de clipes curtos
- Casos: Cenas cinematográficas, B-roll, conceitos rápidos

### 2. fal-video-edit (opendesign)
- API: fal.ai
- Uso: Edição de vídeos existentes com IA
- Funcionalidades: remix de estilo, upscale, remoção de fundo, adição de áudio

### 3. video-hyperframes (opendesign)
- Uso: Animação de quadros contínuos (Hyperframes/Remotion)

### 4. remotion (opendesign)
- Uso: Criação de vídeos programáticos com React
- Casos: Explicações brandizadas, cortes para redes sociais

### 5. youtube-clipper (opendesign)
- Uso: Geração e edição automatizada de clipes do YouTube
- Funcionalidades: extrair vídeo fonte, cortar highlights, legendas, exportar
