# Nível Médio — Prospecção com Imagens

Empresas de porte consolidado em Telêmaco Borba - PR que podem crescer com presença digital.

## Como usar esta pasta

Cada empresa tem uma pasta com:

### 1. `info.md`
- Dados da empresa: nicho, contato, site, Instagram, Google Maps.
- Qualificação: `sem-site`, `site-fraco`, `site-ruim-confuso`.
- Observações sobre a oportunidade.

**Leia primeiro** para entender o perfil do lead.

### 2. `fontes-imagens.md`
- Links diretos do Google Maps e Instagram da empresa.
- Use para **abrir no navegador**, salvar fotos manualmente ou entrar em contato.

### 3. `imagens/`
- Fotos reais baixadas do site próprio da empresa (onde disponível).
- Use estas imagens **para construir o site** — são fotos legítimas do negócio.

### 4. `abordagem.md`
- Texto pronto para WhatsApp ou Instagram DM.
- **Copie e cole**, personalize com o contato da empresa.

### 5. `esqueleto-site.md`
- Estrutura de páginas sugerida para o site da empresa.
- Use como **briefing** pro desenvolvimento.

### 6. `ui-ux.md`
- Diretrizes de design: paleta, tipografia, layout.
- Use como **referência visual** pro frontend.

### 7. `prompt-comando.md`
- Prompt pra IA (Claude Code, Hermes, Codex) gerar o projeto.
- Cole no chat da IA e ajuste com os dados da empresa.

### 8. `objecao-presenca-digital.md`
- Respostas prontas pra objeções comuns ("já tenho Instagram", "não preciso de site").
- Use durante a **abordagem de vendas**.

### 9. `prompt-novas-cidades.md`
- Prompt para reproduzir a prospecção em outra cidade.
- Troque `[CIDADE] - [UF]` e execute.

## Ordem recomendada de trabalho
1. Abra `info.md` — conheça o lead.
2. Abra `fontes-imagens.md` — veja as redes e salve fotos extras.
3. Leia `abordagem.md` — personalize e envie.
4. Se houver interesse, use `esqueleto-site.md` + `ui-ux.md` + `imagens/` + `prompt-comando.md` pra construir o site.
5. Se houver objeção, use `objecao-presenca-digital.md`.

## Sobre o setup MAC + Windows
- **MAC** 24h no servidor: captura e processa.
- **Windows**: armazena e entrega.
- **Antigravity + OpenSquad**: ferramentas pra tocar os projetos.
