# Clientes em Potencial (Prospecção Google Maps)

Prospecção de empresas locais que **não têm site**, têm **site ruim/desatualizado**, ou que poderiam agregar com **site/sistema sob encomenda**.

## Cidade inicial
Telêmaco Borba - PR (polo celulose/Klabin, ~70k hab).

## Estrutura
Cada nicho tem sua pasta. Dentro de cada nicho, uma pasta por empresa com 5 arquivos:
1. `info.md` — nome, contato, redes sociais, qualificação, comentários, fonte (Google Maps).
2. `esqueleto-site.md` — estrutura de páginas/seções do site em potencial.
3. `ui-ux.md` — diretrizes de design, layout, paleta, UX.
4. `prompt-comando.md` — prompt para gerar/rodar o projeto (stack Next.js + Supabase ou estático).
5. `abordagem.md` — texto de abordagem ao cliente (oferta site/sistema, qualidade, agregação).

## Critérios de qualificação
- `sem-site`: não encontrado site próprio (só Instagram/Facebook ou nada).
- `site-ruim`: site existente mas lento, sem responsivo, visual antigo.
- `desatualizado`: site com info defasada (horário, preço, contato errado).
- `sem-sistema`: usa WhatsApp manual / planilha, ganharia ERP/agendamento.

## Como reproduzir para outra cidade
Ver prompt no final do índice ou solicitar ao Hermes: "Faça prospecção Google Maps em [CIDADE] com os mesmos 5 arquivos por empresa".
