## Resumo
Vídeo ensinando a usar o Hermes Agent para automatizar prospecção de leads:
- **AppFi (Apify):** raspagem de leads do LinkedIn
- **Google Sheets:** armazenamento organizado dos leads
- **Hermes:** orquestrador da automação

## Fluxo
1. Prompt pro Hermes descrevendo a automação desejada
2. Hermes faz perguntas pra alinhar (critérios de busca, API keys, etc)
3. Duas partes: configurar Google Cloud (Sheets API) + API key do Apify
4. Hermes conecta e roda a automação
